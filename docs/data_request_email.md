# Data request email: PropertyGuru / iProperty Malaysia

A draft asking for academic access to anonymised rental listing data. iProperty
is part of PropertyGuru in Malaysia, so one email covers both.

**Before sending**
- Fill in every `[bracketed]` part. Send it from your UTP email and copy your supervisor.
- Use the contact or partnerships address on PropertyGuru Malaysia's website. This draft doesn't assume one.
- If UTP can give you a supervisor's letter confirming the project, attach it.
- Answer honestly if they ask how you have collected data so far. The current baseline includes 266 listings
  scraped from iProperty / PropertyGuru on 27 Aug 2026. `data/processed/fallback_no_scrape.json` shows the
  baseline without them.

**To:** [PropertyGuru Malaysia contact]

**Subject:** Academic data request: anonymised rental listing data for a UTP final-year project

Dear PropertyGuru Malaysia team,

My name is [Your name], a final-year [programme] student at Universiti Teknologi PETRONAS,
supervised by [Supervisor name]. My final-year project, RentSafe MY, helps students and other
renters in Kuala Lumpur and Selangor spot rental scams before they pay a deposit. One of its
checks compares a listing's asking rent with typical rents for similar properties in the same
area, because a rent far below market is a common warning sign.

I would like to ask whether you could share anonymised rental listing data for academic use. I
only need these fields for each listing:

- area (district or township)
- property type (condo, apartment, flat, landed, studio or room; master or common for a room)
- number of bedrooms
- monthly asking rent
- listing date

I don't need agent or owner names, phone numbers, addresses, photos, descriptions or listing
links. Listings in KL and Selangor from the last 12 months would be ideal. A smaller sample, or
summary figures such as the median and quartiles of rent per area and property type, would also
help a great deal.

The data would be used only for this non-commercial project. It would be kept securely, seen
only by me and my supervisor, shown in my report only as aggregated statistics, never shared or
republished, and deleted when the project ends in [month year]. I am happy to sign a data-use
agreement, credit PropertyGuru in the report, and share my findings with you.

Thank you for considering this request. I would be glad to answer any questions or arrange a
short call.
